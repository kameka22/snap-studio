Petites améliorations

et une quinzaine de corrections
  • Liste des objetsUn « − » retire un objet du plateau ; « Ajouter 2 objets » suit la sélection.
  • Onglets d’ExplorerPlus de barre d’adresse : Précédent, Suivant et Recharger flottent sur la page.
  • CaméraUne caméra qui n’a pas démarré n’est plus relancée chaque seconde.
  • DécoupeArrêter fonctionne aussi pendant la préparation, sans attendre le moteur.
  • ImprimantesUne impression refusée par l’imprimante est signalée comme telle.
  • FichiersUn G-code enregistré n’en écrase jamais un autre : il est numéroté.
  • WindowsLes noms de fichiers s’affichent en entier dans la feuille de découpe.
  • QualitéLes tests tournent sur chaque pull request : Rust, interface et traductions.
